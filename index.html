Voice Controlled Object Detection Robot Using Arduino

Presenter: YAMEEN SAYYAD Course: Artificial Intelligence & Machine Learning Academic Year: 2025 – 2026

1. Abstract

Robotics and automation technologies are becoming increasingly important in modern engineering applications. This project focuses on the design and implementation of a voice-controlled robot with obstacle detection capability using the Arduino platform. The main objective of this system is to develop an intelligent robot that can move in different directions based on voice commands while also ensuring safe navigation through automatic obstacle detection.

The robot is controlled through a Bluetooth communication system connecting a smartphone to the robot using the HC-05 module. Voice commands given through a mobile application are converted into text commands and transmitted to the Arduino Uno microcontroller. Based on these commands, the Arduino processes data and drives the DC motors via the L298N dual H-bridge motor driver module.

To enhance safety, the robot is equipped with an HC-SR04 ultrasonic sensor that continuously measures distance to nearby obstacles. If detected clearance falls below a predefined threshold (20 cm), the Arduino automatically applies emergency braking, preventing collisions. Overall, the project provides a cost-effective, simple, and efficient robotic platform for assistive mobility, smart surveillance, and automation research.

2. Introduction

Robotics is one of the most rapidly growing fields in modern technology, finding applications across industrial manufacturing, healthcare, military operations, and home automation. Traditional robotic systems rely on manual wired or joystick controllers, which demand constant human attention and can lead to collisions if operator reaction lags.

Modern robotics overcomes these limitations by integrating intelligent voice recognition, wireless telemetry, and sensor-based obstacle avoidance. Voice control provides an intuitive hands-free interface for users, while ultrasonic proximity detection ensures independent navigational safety.

3. Problem Statement

Many existing robotic systems suffer from:

  • Lack of Intelligent Collision Avoidance: Dependency on manual operator intervention causes frequent collisions.
  • Inaccessible Control Mechanisms: Complex physical controllers present steep learning curves for beginners or physically disabled individuals.
  • Prohibitive Implementation Costs: Industrial autonomous navigation units are too expensive for educational and small-scale environments.

This project resolves these issues by delivering an affordable, Arduino-driven voice robot with autonomous collision prevention.

4. Objectives

  1. Voice-Controlled Robotics: Enable smartphone speech input for hands-free directional steering.
  2. Bluetooth Telemetry: Establish stable wireless serial communication using HC-05 at 9600 baud.
  3. Directional Mobility: Coordinate forward, backward, left, right, and stop motion via dual DC motors.
  4. Ultrasonic Detection: Continuously monitor front clearance using the HC-SR04 sensor.
  5. Automatic Collision Prevention: Emergency braking whenever distance is under 20 cm.
  6. Educational Platform: Provide a practical demonstration model for embedded systems engineering.

5. Hardware Components

6.1 Arduino Uno Microcontroller

The central controller based on the ATmega328P MCU running at 16 MHz with 14 digital I/O pins (6 PWM) and 6 analog inputs.

Fig 1 : Arduino Uno Microcontroller Board

6.2 L298N Dual H-Bridge Motor Driver

Controls direction and speed of two DC motors independently (5V–35V, 2A peak per channel).

Fig 2 : L298N Dual H-Bridge Motor Driver

6.3 Ultrasonic Sensor (HC-SR04)

Emits 40 kHz ultrasonic pulses with 2 cm – 400 cm detection range and ±3 mm accuracy.

Fig 3 : Ultrasonic Sensor (HC-SR04)

6.4 Bluetooth Module (HC-05)

Enables wireless RF serial communication with smartphones up to 10 meters distance.

Fig 4 : Bluetooth Module (HC-05)

6.5 DC Geared Motors & Battery Power Supply

Dual high-torque DC gear motors paired with a 12V rechargeable lithium power supply.

Fig 5 & 6 : DC Geared Motors and Battery Supply

7. Applications & Future Scope

  • Industrial Material Transport: Hands-free movement of components in automated warehouses.
  • Assistive Mobility: Voice-directed robotic wheelchairs and assistants for individuals with disabilities.
  • Home Automation & Surveillance: Base platform for domestic cleaning, patrol, and security.
  • Future AI Enhancements: Upgrading with ESP32-CAM computer vision, 360° LiDAR mapping, and IoT cloud telemetry.
